## Why

The user requests final builds, releases and Pages for the independently maintained
projects. Classic Ballance must ship current source and standalone release identity
instead of leaving only the older pre-separation artifacts available.

## What Changes

- Version Ballance 1.0.12, increment the Android build code and rebuild all five
  supported players with complete core/packages/13-level content.
- Validate/package source-matching artifacts, publish v1.0.12 with checksums and
  legal notices, and deploy/verify its matching Web player on Pages.
- Replace the canonical local Mac installation after successful validation;
  remove obsolete generated app copies through the existing installer.

## Capabilities

No new gameplay or publication behavior. This release executes existing platform
and Pages contracts; skip_specs is true. Reballance uses its own ongoing change.

## Impact

Project version metadata, release status documentation and verification evidence.
No physics/level/UI changes are intended. Native IDs, browser save directory,
existing tags/releases and user profiles remain unchanged. Physical Android and
reference-PC checks remain unavailable as previously acknowledged by the user.
